# 屬性訓練器 / Type Trainer / タイプトレーナー

一個以手機使用為主的 Pokémon 屬性相剋練習工具。  
A mobile-first Pokémon type matchup practice tool.  
スマートフォン向けのポケモンタイプ相性練習ツールです。

---

## 中文

### 功能
- 背誦模式
  - 攻擊方：效果絕佳 `2×` / 效果不好 `0.5×`
  - 防守方：弱點 `2×` / 抵抗 `0.5×`
  - 支援單屬性及雙屬性
- 隨機出題
- 錯題重溫
  - 支援倍率題及背誦題
- 完整屬性相剋表
- 錯題優先加權
- 支援中文、English、日本語
- 適合加入 iPhone 主畫面使用

### 效果標示
`★ 4×` 效果無比絕佳  
`◎ 2×` 效果絕佳  
`◯ 1×` 有效果  
`△ 0.5×` 效果不好  
`▼ 0.25×` 效果相當不好  
`☓ 0×` 沒有效果  

### 使用方法
直接開啟 GitHub Pages 網址即可使用。  
iPhone 可使用 Safari 開啟網頁，再選擇「加入主畫面」。

## English

### Features
- Memorize mode
  - Attacker: `2×` Super effective / `0.5×` Not very effective
  - Defender: `2×` Weakness / `0.5×` Resistance
  - Supports single and dual types
- Random quiz
- Mistake review
  - Supports multiplier questions and memorization questions
- Full type matchup chart
- Mistake-weighted question selection
- Supports Traditional Chinese, English, and Japanese
- Designed for mobile and iPhone Home Screen use

### Effect labels
`★ 4×` Extremely effective  
`◎ 2×` Super effective  
`◯ 1×` Effective  
`△ 0.5×` Not very effective  
`▼ 0.25×` Mostly ineffective  
`☓ 0×` Has no effect  

### Usage
Open the GitHub Pages site in your browser.  
On iPhone, open it in Safari and choose **Add to Home Screen**.
